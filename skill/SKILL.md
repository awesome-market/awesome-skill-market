# Deslop

Rules distilled from upstream design skills by the deslop-fusion pipeline. **Do not edit this file** — change `decisions/` or upstream and rebuild.

## The Floor — never ship a violation

- Ship responsive layouts down to mobile, respect reduced-motion preferences, and ensure visual accessibility with harmonious color palettes.
- Autoplay videos must be muted, looped, and playsinline; mark LCP images with fetchpriority=high and preload LCP video posters.
- Maintain sequential heading levels without skips, using h3 for footer column heads and stepping down one level at a time in main content.
- Error messages must describe what broke, why, and what to do in one sentence, tied to the field via aria-describedby and aria-invalid true, shown inline next to fields with focus moved to the first failed field on submit.
- Overlays and dialogs must mark the page behind as inert, close on Escape and backdrop click, include a visible close control, and move first focus to the first interactive element; open dialogs with showModal().
- Give every hover affordance a focus equivalent; never make an interaction hover-only, and make hover and liquid moments do nothing on touch screens.
- Ensure every panel remains visible in order when scripting is absent, provide prefers-reduced-motion fallbacks for every animation, and keep content visible with scripting disabled.
- Include an absolute-positioned skip-to-content link that becomes visible on focus and a skip link to main content.
- Apply pointer-events: none and aria-hidden=true to every texture overlay so it never intercepts input, and measure text contrast against the textured result without dropping below contrast thresholds.
- Treat basics block failures as blocking while their warnings never block, and give every animated moment a static variant for phone and reduced motion.
- Draw a 2px action-color focus ring 2px off the control with no transition, shown immediately without animation, and never hide a focused control under the fixed header.
- Put the place name in image alt text and ensure every image has alt text or an empty string for decorative images.
- Give each navigation group three or four words pointing to an id on that group, mark the main action with aria-current only on the group that performs it, and use a or Link for navigation links to support modifier and middle clicks.
- Give every field a visible label above it and never rely on placeholder or aria-label alone; give every control a name and an aria-label for icon-only buttons.
- The menu button must announce its current state, and group compound controls with focus-within so focus rings cover the whole control.
- Every interactive element must have an accessible name via label, aria-label, or visible text, include keyboard handlers, and ensure all functionality is operable via keyboard without a mouse.
- Async updates like toasts and validation must expose aria-live polite.
- Pause auto-rotating or moving content on hover and focus, and expose a visible pause control for anything moving longer than five seconds.
- Provide a prefers-reduced-motion: reduce fallback for every animation, keyframe, or transform transition — including transition:all on hover — and ship all motion-free states identically.
- Keep input border width constant, build focus rings with outline, share heights with adjacent buttons, and disable controls via opacity, cursor:not-allowed, and the native disabled attribute.
- Give every decorative SVG, canvas, CSS-art element, or icon aria-hidden=true, and give content photographs alt text, empty alt for decorative ones, and role=img with aria-label for drawn mocks.
- Never remove outline without providing an equivalent visible focus indicator, and give every interactive element an instantly visible :focus-visible state.
- Mark required fields with aria-required and a visible word — never colour alone — and label every form control via a label element or aria-label.
- Either label a map directly or mark it aria-hidden and provide a text legend containing every fact it conveys.
- Set aria-invalid and aria-describedby on fields, swap the helper line for the error in reserved space, toggle aria-invalid on validation failure, and run forms with novalidate and data-endpoint.
- Make tab switchers keyboard-operable with role=tablist/role=tab, aria-selected, aria-controls linking tabs to role=tabpanel panels, aria-expanded toggled on the nav toggle, and aria-live polite status text.
- Put a .skip-link as the first child of the header wrap pointing to main#top, keep it off layout until first Tab, ensure tab order equals reading order, never set tabindex above 0, and never let sticky headers, footers, or overlays cover the focused element.
- Use button for actions and a or Link for navigation instead of div with onClick, give every link and control outside running text at least 44px of height, and keep targets under 8px apart from both being targets.
- Provide tap, click, and keyboard alternatives for gesture-only actions unless truly essential, and implement custom widgets with appropriate ARIA roles, states, and properties.
- Ensure text placed on an effect reads at a contrast ratio of at least 4.5:1.
- Keep all copy in its finished place so content is readable without motion and never hide a headline on load; content must be fully readable at rest without script and under reduced motion.
- Limit grain to a single tile made at load, never animated and never over UI, text or photographs.
- Never copy a reference site's code, copy, pictures, or signature effect.
- Resolve every icon through scripts/icons.mjs and never fetch, tint, or judge an icon at runtime or call a CDN for one.
- Only render a map when the brief provides the street; otherwise show the visit's photograph.
- Never use retired or renamed effect ids; treat mesh-gradient as gradient-mesh and iridescent-foil as fluted-glass, and keep riso-print, paper-texture, and liquid-chrome out entirely.
- Use text fields not type=date on non-English pages and never put a photograph, texture, or glass under the form.
- Set <html data-type="place"> and <meta name="page-kind" content="place">, and scope place CSS under html[data-type="place"].
- Ship base.css inside the base layer with layer(base) so its element rules land after Preflight and below utilities.
- When a shader fails, a frame throws, the first frame is one flat colour, or a photograph cannot load, show the plain cover-cropped photograph and remove the overlays.
- Warn before navigation when changes are unsaved using beforeunload or a router guard.
- Refuse any shader that uses a GLSL ES reserved word and fall back to the still image.
