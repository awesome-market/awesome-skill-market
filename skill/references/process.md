# process

- **(floor)** Give every interactive element an instantly visible :focus-visible state, never removing outline without replacing it with an equivalent focus style.
- **(floor)** Make all controls keyboard-operable with correct semantics: use button for actions and a/Link for navigation, implement custom widgets with ARIA roles/states/properties, and group compound controls with focus-within so focus rings cover the whole control.
- **(floor)** Label every field with a visible label above it (via label element or wrapping, never placeholder or aria-label alone), mark required fields with aria-required and a visible word rather than colour alone, and ensure labels are clickable through htmlFor or wrapping.
- **(floor)** Validate on submit, set aria-invalid and aria-describedby on fields with errors named by field, show errors inline next to fields, swap helper text for errors in reserved space, and move focus to the first failed field.
- **(floor)** Ship responsive down to mobile with visible keyboard focus and reduced-motion respect; keep all copy in its finished place so content is readable without motion, never hide a headline on load, and ensure the hero stands as written without script under reduced motion, in print, and with data-motion=off.
- **(floor)** Include a pause button in the bottom-right corner of a turning product's frame; interactive media needs keyboard support while decorative media must hide from assistive tech.
- **(floor)** Give every interactive element a visible :focus-visible ring (at least 3:1 contrast, 2px action colour placed 2px off the control with no transition) and never remove the outline without providing an equivalent visible focus indicator.
- **(floor)** Ensure all functionality is operable via keyboard without a mouse, provide keyboard handlers on interactive elements, and give checkbox/radio labels and controls a single shared hit target without dead zones.
- **(floor)** Maintain hierarchical h1-h6 headings progressing one level at a time, include an absolute-positioned skip-to-content link visible on focus as the first child of the header pointing to main content, and never use tabindex above 0.
- **(floor)** Provide prefers-reduced-motion fallbacks (single still frame, no hover/pause/slow turns, context freed) for every animation and transform including transition:all, keep content visible with scripting disabled, and ensure everything is readable at rest without script and under reduced motion.
- **(floor)** Make destructive actions undoable or confirmed, expose async updates (toasts, validation) as aria-live polite, announce the menu button's current state, and ensure content is fully readable at rest since motion only adds to an already whole page.
- **(floor)** Render named tools, apps, and file types as real, correctly colored icons fetched via icons.mjs only when the product integrates them, paste fragments from their slot at true size from meta.json without scaling, and cap cards at five tiles.
- **(floor)** Ship stills by default with at most one live context per page, route non-moving effects through still() or fill(...,{still:true}) to draw once and free their context, pause off-screen and hidden-tab effects, drop pixel ratio when frames exceed 21-24ms, and under reduced motion render dither objects as a single still line drawing without WebGL or pause controls.
- **(floor)** Limit grain to a single non-animated tile made at load, never place it over UI, text, or photographs, use client photographs or renders for texture, logos, transparent glass, draping cloth, freeform organic shells, and anything thinner than a texel, and use still low-contrast grain-gradient inside chips, pills, and bars without silk, glass, or metal sheen.

- **(floor)** Never place a live effect or moving canvas inside a card, never animate a card on scroll, keep shaders and WebGL effects off place, product, and service pages, and keep image-mode pages free of canvas and WebGL contexts.
