# process

- **(floor)** Ship responsive layouts down to mobile, respect prefers-reduced-motion everywhere (including identical textures and no-motion fallbacks), and ensure content remains readable and visible without motion.
- **(floor)** Give every interactive element an instantly visible :focus-visible state, keep tab order matching reading order with skip links reachable first and never below the header, and ensure all functionality is operable via keyboard without a mouse.
- **(floor)** Use semantic elements (button for actions, a/Link for navigation, label via element or wrapping) over ARIA when semantics exist, give every control a visible label above it (never placeholder or aria-label alone), and ensure every interactive element has an accessible name.
- **(floor)** Validate on submit with aria-invalid and aria-describedby errors named per field, move focus to the first failed field, show errors inline, and expose all eight control states including :active and :disabled unless the control is not a form control and has no aria-disabled anywhere.
- **(floor)** Apply aria-selected, aria-controls, aria-expanded, aria-pressed, aria-current, aria-required, and aria-hidden correctly per component, prefer semantic HTML over ARIA roles, and mark decorative icons and hidden maps appropriately.
- **(floor)** Mute, loop, and playsinline autoplay videos; preload LCP video posters and mark LCP images high priority; pause turning product frames via a bottom-right button; keep focus rings on compound controls; and expose interactive media to keyboard while hiding decorative media from assistive tech.
- **(floor)** Make tab switchers keyboard-operable with aria-selected and aria-controls, flip aria-expanded on menu toggles, use a/Link for navigation to support modifier clicks, and apply scroll-margin-top to heading anchors so targets remain visible.
- **(floor)** Give every interactive element a visible focus ring via :focus-visible with at least 3:1 contrast against adjacent colors; never remove the outline without replacing it with an equivalent indicator, and draw it immediately without animation.
- **(floor)** Provide a prefers-reduced-motion fallback for every animation, keyframe, or transform (including transition:all): show a single still frame, keep content visible with scripting disabled, and free animation context immediately.
- **(floor)** Every hover or pointer affordance must have a keyboard focus equivalent and never be hover-only; interactive elements must include keyboard handlers, and gesture-only actions must provide tap, click, and keyboard alternatives unless truly essential.
- **(floor)** Give every control an accessible name (aria-label for icon-only buttons), keep labels visible, ensure shared hit targets without dead zones for checkboxes/radios, and always allow pasting while keeping submit buttons live until pressed.
- **(floor)** Maintain hierarchical headings progressing one level at a time, mark custom widgets with ARIA roles/states/properties, place a skip-to-content link as the first focusable element pointing to main content, and never let overlays or fixed headers cover focused elements.
- **(floor)** Overlays and dialogs must inert the page behind them, move initial focus to the first interactive element, close on Escape and backdrop click, include a visible close control, announce their state, and expose pause/stop/hide controls for motion longer than five seconds.
- **(reflex)** Make destructive actions undoable or confirmed, and open command palettes immediately on shortcut with focus retained and highlight moved by transform without shifting rows.
- **(floor)** Render named tools, apps, and file types as real, correctly colored icons fetched via icons.mjs only when the product integrates them, paste fragments from their slot at true size from meta.json without scaling, and cap cards at five tiles.
